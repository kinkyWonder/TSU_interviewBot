# AI Mock Interviewer

Веб-приложение для проведения симуляции технического собеседования в IT-сфере. Сервис генерирует вопросы под выбранную специальность, оценивает ответы пользователя, рассчитывает балл и формирует итоговый фидбек.

## Приватность и особенности использования

* Анонимность: проект работает без регистрации и авторизации.
* Сохранение сессии: текущий прогресс собеседования сохраняется в `localStorage` браузера, поэтому при перезагрузке страницы сессия не сбрасывается.
* Режим работы: приложение оптимизировано строго для одиночного домашнего использования (локальный запуск на одном компьютере).
* Необходимые доступы: для работы приложения требуется ваш личный API-ключ GigaChat.

## О формате разработки

Проект создан в формате vibe coding (AI-assisted development). Весь код бэкенда и фронтенда написан нейросетью по моим текстовым запросам.

Моя часть работы заключалась в следующем:
* Провел ресерч и выбрал формат приложения.
* Изучил доступные нейросети по ценам и условиям, остановив выбор на GigaChat API.
* Спроектировал логику работы приложения, структуру экранов и цепочку промптов.
* Проводил тестирование, находил ошибки в работе кода.

## Возможности приложения

* Генерация вопросов по указанной IT-специальности с выбором сложности (Стандартный / Продвинутый).
* Проверка каждого ответа нейросетью: выделение плюсов, минусов и выставление балла от 0 до 10.
* Расчет итогового процента успешности собеседования.
* Генерация общего резюме и специального промпта для AI-ментора, чтобы проработать слабые места.
* Проверка на пустые ответы: если пользователь ничего не ответил, сервер не делает лишних запросов к API и сразу выводит 0%.

## Стек технологий

* Backend: Python, Flask, SDK gigachat
* Frontend: HTML, CSS, JavaScript (Vanilla JS, Fetch API)
* AI-модель: GigaChat-3-Ultra

## Структура проекта

* app.py — Flask-сервер, обработка API-эндпоинтов, связь с нейросетью.
* templates/index.html — разметка приложения (Single Page Application).
* static/css/style.css — визуальное оформление и стили компонентов.
* static/js/main.js — логика клиента, отправка запросов, автосохранение.

## Как запустить

1. Клонировать репозиторий:
   git clone https://github.com/kinkyWonder/TSU_interviewBot.git
   cd TSU_interviewBot

2. Установить библиотеки:
   pip install flask gigachat

3. Указать авторизационный ключ GigaChat в файле app.py (константа AUTH_KEY).

4. Запустить приложение:
   python app.py

5. Перейти в браузере по адресу:
   http://127.0.0.1:5000/
